# Context Orb · UI / UX

版本：0.3.0 · 2026-09-06

悬浮球提供安静入口，面板解释“这一步有哪些依据”。保留陶瓷球、墨绿操作和琥珀失败状态，未知为中性灰。静态环不表示容量或熵值百分比。

| 状态 | 标签 | 含义 |
| --- | --- | --- |
| healthy | 所列检查通过 | 声明范围内的文件条件在采集时通过 |
| watch | 检查未通过 | 至少一个实际检查失败 |
| unknown | 证据待补齐 | 尚无匹配报告或存在未核验条件 |

总览显示固定会话、检查结果、完成与待核验数量、采集时点和入口。详情区分字面条件、来源声明、文件 SHA-256 与未验证观察。账本保留有效、作废和假设条目及替代关系。绿色始终限定为所列检查，换会话收益未评估。

## 交互

- 单击、Enter、Space 展开收起；拖动定位；右键不切换；Escape 返回球体焦点。
- 手动固定 A 后 B 更新不切换；暂缓提醒展示按会话隔离。
- 查看历史时明确标注历史收据，返回概览恢复最新结果。
- 网页有四个虚构场景，失败可模拟修改后重新采集；原生没有模拟检查按钮。
- 复制检查指令明确提示尚未运行。简报可编辑，按用户确认的文本精确复制。
- 未完成约束和假设继续显示未知；简报可用于原会话纠正或用户自行选择的新会话。
- 支持深浅主题、键盘焦点、减少动态效果。当前暂缓只控制界面展示，系统通知尚未实现。

## 窗口与验收

原生折叠 92×92、展开 382×690 logical px；球体操作区 80×80。面板有界滚动，切换视图重置内部滚动。保留 Dock/任务栏入口。
