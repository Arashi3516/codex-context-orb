# Context Orb · UI / UX

版本：0.4.0 · 2026-09-06

悬浮球提供安静入口，面板把脏度线索、上下文容量与可选压缩次数分开。核心颜色表示检查依据中的风险，外环表示有来源的容量读数；真实读数缺失时使用中性虚线环和“未接入”，不以 0% 替代。

| 状态 | 标签 | 含义 |
| --- | --- | --- |
| 柔绿 / ✓ | 所列依据一致 | 声明范围内的文件条件在采集时通过 |
| 暖橙 / ! | 发现检查偏差 | 至少一个实际检查失败 |
| 琥珀 / ? | 疑点待核验 | 有效条目存在尚未独立验证的观察 |
| 中性灰 / · | 尚未评估 / 证据待补齐 | 尚无匹配报告或存在未核验条件 |

这些状态不是整个上下文的污染率，也不是模型已遗忘要求的证明。容量很高、压缩很多次，都不会改变风险颜色。真实 hook 接入目前没有可核验的上下文容量或累计压缩次数；v0.4 数值环仅在明确标注的演示数据中显示。PostCompact 只证明收到一次完成事件，不能恢复累计次数。

总览显示固定会话、独立指标、通过/偏差/未知数量和采集时点。详情区分字面条件、来源声明、文件 SHA-256 与未验证观察。账本保留有效、作废和假设条目及替代关系。绿色始终限定为所列检查，换会话收益未评估。

## 交互

- 单击、Enter、Space 展开收起；拖动定位；右键不切换；Escape 返回球体焦点。
- 手动固定 A 后 B 更新不切换；暂缓提醒展示按会话隔离。
- 查看历史时明确标注历史收据，返回概览恢复最新结果。
- 网页有四个虚构场景，失败可模拟修改后重新采集；原生没有模拟检查按钮。
- 复制检查指令明确提示尚未运行。简报可编辑，按用户确认的文本精确复制。
- 未完成约束和假设继续显示未知；简报可用于原会话纠正或用户自行选择的新会话。
- 支持深浅主题、键盘焦点、减少动态效果。当前暂缓只控制界面展示，系统通知尚未实现。
- 球体动态配色默认开启，可切为中性色；状态符号仍保留。容量仍使用独立冷色环。颜色过渡 200ms，无持续呼吸动画。
- 压缩次数默认隐藏，可在设置中开启。未接入的累计次数显示“未记录”。

## 磁吸

窗口吸附三档为「仅限 Codex 窗口｜关闭｜所有窗口」，默认 Codex。拖动后松手必停靠：落点在允许吸附的可见窗口内，选择该窗口最近的边；其他位置选择当前屏幕工作区最近的边。关闭窗口吸附时始终回到屏幕边缘。没有 CLI、手动窗口绑定或屏幕吸附开关。

macOS 通过系统提供的 `com.openai.codex` bundle ID 识别 Codex。Windows 当前没有已验证的 Codex 包身份，Codex 档明确不可用；屏幕与所有窗口模式有原生实现，仍需 Windows 真机验收。

按下时保留抓取位置，位移达到 4 logical px 后才移动。拖中自由跟随，松手按鼠标落点到边框的距离停靠；优先贴窗口外侧，空间不足则贴内侧。最前方窗口不在允许范围时回到屏幕，不穿过遮挡去选择背后窗口。单击不重新定位；松手后移动鼠标不改变这次手势。释放时刷新窗口边界，已停靠窗口的接触状态每 2 秒复核一次；静止时不追随其他窗口移动。原生只读取可见窗口边界与所属应用身份，不读取标题、终端、对话或截图，也不移动其他应用。

原生移动只写 Orb 自己的窗口。macOS 关闭原生窗口/背景拖动，设置禁止全屏平铺；Windows 清除自己的可缩放和最大化样式并刷新窗口边框，移动采用物理像素取整。保留 Dock/任务栏入口，不修改系统全局平铺或 Snap 设置。这些属性和移动路径已按公开 API 实现，是否消除全部桌面边缘平铺行为仍以真机拖动结果为准。参考：[Apple 窗口移动属性](https://developer.apple.com/documentation/appkit/nswindow/ismovable)、[Apple 全屏平铺属性](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/fullscreenallowstiling)、[Windows 窗口样式](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-styles)、[Windows 窗口定位](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)。

## 窗口与验收

原生折叠 92×92、展开请求尺寸 382×690 logical px；球体操作区 80×80，四周保留 6px 留白。停靠计算使用 92×92 球体区域，面板选择空间更大的一侧展开。展开、收起与设置变化保持球体位置；拖中固定展开方向，松手后再选择方向。可用空间不足时缩小面板并保持可滚动；负坐标和 DPI 在平台坐标空间中处理。保留 Dock/任务栏入口。
