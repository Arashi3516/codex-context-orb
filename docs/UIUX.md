# Context Orb · 悬浮球 UI / UX

版本：0.1.0 框架与设计预览 · 2026-09-06

## 产品目标

帮助正在使用 Codex 的人判断“当前步骤继续做”和“下一阶段换一个新会话”的时机。球体是一个安静入口；解释与决定留在可展开面板中。

用户不需要理解 token 采集链路才能使用产品，但需要看清：正在关注哪段会话、数据是否可信、为什么收到建议。

## 视觉方向

轻盈、克制、有触感。柔白陶瓷球体配细线状态环，墨绿色为主操作，琥珀和暖珊瑚用于提升注意程度。正常状态无持续闪烁，无呼吸动画占用注意力。

- 外层操作区域：80 × 80 CSS px；陶瓷球心：62 px。
- 原生折叠窗口：92 × 92 logical px，预留抗锯齿和阴影空间。
- 展开面板：340–354 px 宽；内容在小窗口内有界滚动。
- 标题字体：DM Sans Variable + 中文平台字体；展示页标题局部使用宋体。
- 颜色由 CSS variables 管理，浅色 / 深色共用组件。
- 球体进度环只表达容量占用。不是综合“智力”或“脏度分”。

| 状态 | 色彩 | 标签 | 面板含义 |
| --- | --- | --- | --- |
| healthy | 墨绿 | 余量充足 | 容量压力较低；不证明语义一定清晰 |
| watch | 琥珀 | 留意余量 | 关注下一阶段的交接时机 |
| handoff | 暖珊瑚 | 建议交接 | 容量接近上限，建议保存进展 |
| unknown | 灰绿 | 等待数据 | 尚未固定、缺失、异常或过期数据 |

容量初始阈值：75% 提醒、90% 建议交接。直接用未四舍五入的比率做判定，界面只对展示值取整。反复压缩可以提升到“留意”，不能单独强制交接。未来可配置阈值，需要保留迟滞、跨阈值去重、会话隔离和稍后提醒。

## 信息层级

1. **会话身份**：面板顶部显示具体会话，显著标注“手动固定”。不把最新活动描述成当前前台。
2. **一句建议**：短标题 + 原因，不使用吓人的失败/损坏文案。
3. **真实用量**：占用率、分子/分母、压缩次数；不能取得的值显示“—”。
4. **下一步**：准备交接、稍后提醒；用户控制新会话的创建。
5. **来源与设置**：模拟数据/接入未完成必须可见。隐私、主题与暂停控制。

## 交互

| 动作 | 行为 |
| --- | --- |
| 单击球体 / Enter / Space | 展开或收起面板 |
| 拖动球体 | 浏览器中在预览区域内定位；桌面端移动独立窗口 |
| Escape | 收起面板，焦点返回球体 |
| 点击会话行 | 打开手动固定列表，显示具体身份 |
| 模拟后台更新 | 更新 B 的事件，验证 A 的绑定保持不变 |
| 准备会话交接 | 打开可编辑模板，不假装已完成自动摘要 |
| 复制模板 | 写入剪贴板；失败时给出手动复制提示 |
| 稍后提醒 | 当前会话暂停展示提醒 10 分钟，球体显示静音标识 |
| 切换主题 | 使用同一套布局与状态，保存外观偏好 |

当前“稍后提醒”用于交互原型：系统推送和自动触发通知尚未接入。量产版本的去重/迟滞需在真实事件链上另外验收。

## 演示与真实数据

浏览器展示页明确使用模拟会话，供审查颜色、绑定、模板与布局。原生窗口默认读取自有 hooks 目录，没有 demo 数字自动兜底。

本期 hooks 只传入事件元数据，无法提供上下文占用。真实来源因此保留未知；不会把事件收到时间、总轮数或模型名称换算成伪 token 用量。

## 语义提示的后续设计

“容量压力”与“内容杂乱”分区显示。后者只能通过可解释证据给建议，例如不同目标反复切换、相互矛盾的约束尚未解决。不能单凭长时间、大量 token、用户纠正或情绪词判定质量下降。

语义判断第一阶段由用户明确请求 skill 检查；后台模型分析需另行验证隐私、费用与收益，并提供关闭入口。

## 可访问性与窗口行为

- 交互控件保留可见键盘焦点，不依赖颜色单独表达状态。
- 主要按钮有文本；纯图标按钮有 accessible name。
- prefers-reduced-motion 下关闭出入动画和过渡。
- 文字与用量可选取；交接模板可直接编辑。
- 弹窗不能在初次页面加载时把整个页面滚动到球体。
- 正式窗口需要补充多显示器、屏幕缩放、任务栏/Dock、休眠恢复、坐标持久化与托盘找回。
- 目前保留任务栏/Dock 入口，避免在没有完整托盘恢复能力时隐藏掉唯一入口。

## 本轮 UI 验收清单

- 桌面与窄屏展示页：主要控件可达，无横向溢出。
- 四个状态切换，UNKNOWN 不出现可疑百分比。
- A 固定 / B 后台更新，切换到 B / 回到 A，解除固定。
- 面板收起/展开、球体拖动、Escape/键盘、主题来回切换。
- 模板编辑、复制成功或明确失败；不自动创建会话。
- 暂停与恢复、设置、说明弹层的完整返回路径。
- 小窗口与深色模式的单独视觉检查。
