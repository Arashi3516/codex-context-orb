# Context Orb · UI / UX

版本：0.2.0 · 2026-09-06

球体是安静入口，面板解释“当前上下文是否仍支持下一步”，用户决定何时整理交接。

保留陶瓷球、墨绿主操作、琥珀关注和暖珊瑚建议。静态分段环表示类别，无容量或熵值百分比。支持深浅主题、可见键盘焦点与减少动态效果。

| 状态 | 标签 | 含义 |
| --- | --- | --- |
| healthy | 脉络清晰 | 本次评估未发现仍影响执行的冲突 |
| watch | 需要留意 | 先澄清具体疑点 |
| handoff | 建议新开 | 压缩后问题复现，有不同执行偏差印证 |
| unknown | 等待评估 | 无匹配且有效的充分证据 |

面板依次显示固定会话、建议、已观察压缩与疑点数、来源、证据入口和操作。多次压缩后清晰场景必须可演示；建议新开必须能查看依据。绿色不保证持续质量。

## 交互

- 单击/Enter/Space 展开收起，拖动定位，右键不切换；Escape 返回球体焦点。
- 手动固定 A 后 B 更新不切换；静音按会话隔离，切回仍保留。
- 依据页显示目标、问题、影响与复现标签、具体来源。网页可模拟澄清复查；原生不提供假评估按钮。
- 证据不足提供评估指令，复制后明确尚未运行。
- 交接预填有效目标和下一步，疑点单独标为待澄清；用户填写有效约束、验证结果和作废信息后复制。
- 当前静音只控制展示，系统通知未实现；设置注明手动评估和准确率边界。

## 窗口与验收

原生折叠 92×92、展开 382×690 logical px；球体操作区 80×80。面板有界滚动，返回概览时重置内部滚动。保留 Dock/任务栏入口。

浏览器演示均为虚构。验证桌面/窄屏、深浅主题、依据、澄清、复制、静音、绑定和键盘。Windows 真机、多显示器、缩放、休眠、托盘和坐标持久化需独立验收。
